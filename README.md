## 🚀 Features

* 🔐 **User Authentication** — Sign up & sign in pages
* 👤 **User Profile Management** — Personal info, social links, contact details
* 📝 **Multiple Post Types**:

  * 📄 General Posts
  * 📚 Research Papers
  * ❓ Questions
  * 💼 Job Postings
  * 🤝 Collaboration Requests
* 🎯 **Categorization by Discipline**:
  *Physics*, *Chemistry*, *Biology*, *Computer Science (CSE)*, *Electrical & Electronic Engineering (EEE)*, *Law (LL.B)*
* 📱 **Responsive UI** — Built with Bootstrap 5
* 🌐 **Social Media Integration** — Icons for Facebook, Twitter, GitHub, Instagram, LinkedIn, and more

## 📖 Usage

1. **Open** `landing-home.html` in a browser
2. **Navigate** categories via the menu or sign up/login
3. **Access Profile** — `userProfile.html` to manage info & posts
4. **Create Posts** — Add papers, questions, jobs, or collab requests
5. **Explore Content** — View others’ work and connect
